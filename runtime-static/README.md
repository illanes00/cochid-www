# Cochid principal

Fuente canónica del contenido estático servido por `https://cochid.cl/` desde
el 2026-08-13. El baseline provenía de
`/srv/projects/cis/projects/cochid/frontend/index.html`, un directorio sin Git.
El release vigente se exporta desde este subárbol a un directorio inmutable.

El único contenido público del apex es `index.html`. La configuración efectiva
de Caddy, los logs y los releases quedan fuera de Git. La aplicación Flask que
permanece en la raíz del repositorio es legado no desplegado y no debe usarse
como fuente de producción.
